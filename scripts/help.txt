AI Manga Studio

  ./Studio.command                         Open the interactive menu
  ./Studio.command -p "A fox in a garden"  Generate a reviewed 4K PNG

  -p, --prompt TEXT       Describe the scene in Chinese or English
  -o, --output-dir DIR    Copy accepted files to DIR (one subfolder per release)
  --style TEXT            Optional medium or style, e.g. anime-key-visual or "Japanese watercolor"
  --base-model MODEL      auto (default) or qwen-image-2512 for an original text composition
  --aspect RATIO          auto (default), 2:3, 3:2, 9:16, 16:9, 1:1
  --seed N                Starting seed (default random)
  --candidates N          Drafts per round, 1 to 8 (default 3)
  --max-rounds N          Maximum rounds this run (default 0, retry until accepted)
  --print-method METHOD   First 4K pass: auto (default), restoration (SeedVR2) or tiled
  --8k                    Also render, inspect and export an 8K PNG
  --native-4k             Draw on a native 4K canvas
  --full-8k-diffusion     Enable 8K and use full-canvas tiled diffusion
  --draft                 Stop after producing and checking drafts
  --background            Run in the background and print the job directory
  --job DIR               Resume a project job
  --from-image PNG        Start from an existing image
  --review-print PNG      Review an existing 4K print against its --reviewed-image draft
  --set-output-dir DIR    Save a default export folder; use --reset-output-dir to clear it
  --gallery               Open the offline gallery
  --editor                Open the node editor
  --install               Install or verify dependencies and models
  --advanced-help         Show all generation and repair options
  -h, --help              Show this help without installing or starting any service

Without an export folder, open images/new-jobs/<job>/4K.png (also 8K.png with --8k).
